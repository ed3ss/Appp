# Logo Trajets

Icône créée avec l’outil intégré de génération d’images, le 20 octobre 2026. Concept : route en forme de T et repère GPS, menthe sur charbon. Original conservé dans `logo-original.png`, déclinaison technique 1024 px dans le catalogue iOS. Aucun texte ni coin arrondi intégré.

## Prompt utilisé

Use case: logo-brand. Asset type: final iOS app icon for Trajets, a private GPS trip recorder. Create one square 1024x1024 opaque app icon, edge to edge very dark charcoal background (#0B1417), NOT a mockup. Center a distinctive bold mint green (#55E6BF) symbol combining a flowing road / GPS route and the letter T, with a small circular destination endpoint. Minimal premium vector-like geometry, strong legibility at tiny icon sizes, generous safe margins around symbol, subtle depth only, crisp edges. No words, no captions, no additional panels, no device frame, no rounded outer corners (iOS will mask), no white border, no watermark. Match a dark French travel/speedometer app with mint accents.
